# Lab experience and Mac transfer

## Outcome

Use one visual language across the lab, operate reviewed promotions from the
release tree, and prepare an accurate transfer guide for a Mac host.

## Review batches

1. Shared design tokens, accessible controls and navigation across control,
   release, decision, progress, comparison and saved notebook pages.
2. Promotion controls attached to the release tree. Existing named operations,
   approval checks, evidence and coordinator locking remain authoritative.
3. Current documentation and runbook reconciliation, Mac prerequisites, transfer
   procedure and platform checks. Native Mac execution remains an explicit
   outstanding acceptance check.

Each batch is committed and proposed for human acceptance. No main merges or
promotion, load test or model inference is performed by this implementation.

## Verification

Check desktop and narrow layouts, keyboard navigation, authentication and
existing page behaviour. Exercise action eligibility, stale release rejection,
reader restrictions and submission retries using disposable fixtures. Inspect
Mac commands against scripts and upstream platform guidance; do not claim native
execution from a Windows or emulated run.
