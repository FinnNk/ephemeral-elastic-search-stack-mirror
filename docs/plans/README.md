# Delivery plan

The [batch roadmap](roadmap.md) tracks the remaining lab work and its review state. The [million-product plan](million-product-scale.md) and [next concurrency plan](concurrency-isolation.md) record intent, constraints and acceptance checks. Each batch is committed on a branch and submitted as a pull request. Later pull requests may target the preceding branch so work can continue while the stack awaits review; merge them in order.

The [prototype design](../prototype-design.md) owns the architecture and provisional quantitative targets. These plans organise delivery without replacing that design.
