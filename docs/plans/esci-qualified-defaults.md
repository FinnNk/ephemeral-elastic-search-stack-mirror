# Restore qualified ESCI defaults

Replace the temporary demo judgement policy with independently qualified labels after the investigation resumes. This plan does not authorise the held Decider2B survey.

## Intent and constraints

- Keep the full English ESCI catalogue, frozen query suite and source precedence.
- Retain demo predictions and reports with their original unqualified provenance.
- Select additional models only after independent label-quality and serving checks.
- Preserve the fitting reservation and excluded specialist queries. Model agreement cannot replace independent reference labels.
- Keep the 80% coverage requirement and existing result/ranking rules.
- Obtain human review before changing protected policies, trusted CI pins or main.

## Acceptance criteria

| Check | Required result |
| --- | --- |
| Quality evidence | Independent confirmation meets the reviewed precision and harmful-error requirements; report missing actual-gap references |
| Serving | Exact model/version/digest, contract validation and repeatable numerical behaviour |
| Coverage | Fresh public-API results reach 80% using qualified labels on each selected variant |
| Strict restore | Published/qualified snapshot replaces the demo default; protected policy no longer accepts demo evidence |
| Regression | Retained demo reports remain readable; no migration or compatibility adapter |
| Delivery | Reviewed implementation/source PRs and trusted CI pin updates after acceptance |

## Work sequence

1. Review the completed category surveys and decide which remaining investigation to resume. Honour the separate execution hold.
2. Obtain independent references and qualify useful incremental sources.
3. Freeze a qualified judgement set and capture fresh API results.
4. Replace default input and protected policy pins; verify strict and rejection paths.
5. Record results, update the roadmap and create the next review batch.
