# Local evidence records

Each record describes a particular revision, input set and local experiment.
Read its conditions and limitations before interpreting a timing, score or
successful check. Later service changes do not change the recorded result.

- A successful run is not a timing percentile or capacity estimate.
- Synthetic labels measure agreement with the declared model, not customer benefit.
- A tooling or fixture proof is not a human release decision or a cloud result.
- Old URLs, run IDs and resource names identify that experiment; use the
  [current guides](../README.md#current-procedures) for operation.

The [roadmap](../../plans/roadmap.md) owns current status. These records retain
failures, hashes, measurements and original follow-up statements, including work
that was completed later.
