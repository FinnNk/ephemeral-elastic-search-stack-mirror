# Additional query-set judgements

Use these frozen labels with the matching `sneakers` and `redis-rewrites`
query files and the frozen `esci-gb-v1` catalogue. Other catalogue releases need
their own compatible labels. Both sets are advisory. Their outcomes are measured against the
normal comparison limits and shown separately from whether they block promotion.

| Set | Queries | Labelled pairs | Coverage per side in the retained capture |
| --- | --- | --- | --- |
| sneakers | 4 | 54 | 36/40 (90%) |
| redis-rewrites | 18 | 252 | 162/180 (90%) |

The labels were generated by `gpt-6-luna` and accepted as-is by the lab owner on
16 October 2026. They retain model provenance and are not independently qualified
gate labels. The loader accepts this explicitly authorised data for advisory
sets; marking it Required is rejected. The standard sets and their labels are
unchanged. The 80% coverage requirement is unchanged.

Grades use ESCI: Exact 3, Substitute 2, Complement 1 and Irrelevant 0. Each row
contains its rationale and the hash of its query/product input. The manifest
pins the catalogue, query bytes, labels, compressed inputs and retained captures.
Product data is derived from Amazon ESCI and ESCI-S; imported licence and notice
files accompany it.

A deterministic pair was omitted per query on each side, independently of rank
and relevance score. `omitted-pairs.json` records the omissions. New results can
change coverage: 90% describes the packaged capture, not every future build.
The existing resolver can assess newly returned pairs; unavailable answers stay
unjudged. It does not regenerate or replace these frozen labels.

New labs copy these files from the installer repository. No model download,
additional inference service, API credential or separate data import is needed.
When changing this data, publish a new source revision and review its release
check plan; historical reports keep their original label snapshots.
